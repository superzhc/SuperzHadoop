# 系统表

> 系统表是 PostgreSQL 数据库存放结构元数据的地方，它在 PostgreSQL 中表现为存放有系统信息的普通表或者视图。

|                 | 描述                                                                                 |
| --------------- | ------------------------------------------------------------------------------------ |
| **系统表**      |                                                                                      |
| `pg_namespace`  | 用于存储命名空间                                                                     |
| `pg_tablespace` | 存储表空间信息                                                                       |
| `pg_database`   | 存放了当前数据集中数据库信息                                                         |
| `pg_class`      | 存储表及与表类似结构的数据库对象信息，包含索引、序列、视图、复合数据类型、TOAST 表等 |
| `pg_type`       | 存储数据类型信息                                                                     |
| `pg_attribute`  | 存储表的属性信息                                                                     |
| `pg_index`      | 存储索引的具体信息                                                                   |
| **系统视图**    |                                                                                      |
| `pg_stats`      | 规划器统计                                                                           |
| `pg_tables`     | 表                                                                                   |
| `pg_views`      | 视图                                                                                 |

## `pg_database`

**属性表**

| 属性名          | 描述                                                                       |
| --------------- | -------------------------------------------------------------------------- |
| `dataname`      | 数据库名称                                                                 |
| `datdba`        | 数据库的拥有者                                                             |
| `encoding`      | 该整数表示数据库的字符集编码，比如 0 表示 SQL_ASCII 编码；6 表示 UTF8 编码 |
| `datcollate`    | 数据库的 LC_COLLATE 设置                                                   |
| `datctype`      | 数据库的 LC_CTYPE 设置                                                     |
| `datistemplate` | 该数据库是否可以作为创建其他数据库的模板                                   |
| `datallowconn`  | 数据库是否允许连接，如果取值未假表示该数据库不允许任何人连接               |
| `datconnlimit`  | 数据库允许的最大并发连接数，如果值为 -1 表示对并发连接没有限制             |
| `datlastsysoid` |                                                                            |
| `datfrozenxid`  |                                                                            |
| `dattablespace` | 数据库所在的表空间                                                         |
| `datconfig`     | 数据库定义的 GUC 参数                                                      |
| `datacl`        | 存放对于该数据库的访问权限列表                                             |
