# 元数据查询

## 元数据

### 获取 Tables

```sql
SELECT database, name AS table_name
FROM system.tables
WHERE name NOT LIKE '.inner%'
```

### 获取 Table 描述

```sql
SELECT database
    , name                AS table_name
    , comment
    , formatRow('JSONEachRow', null) AS properties
FROM system.tables
WHERE name NOT LIKE '.inner%'
```

### 获取 Columns

```sql
SELECT database
    , table AS table_name
    , name
    , type
    , comment
FROM system.columns
WHERE database = '{schema}'
ORDER BY database, table, position
```
