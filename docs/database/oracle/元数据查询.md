# 元数据查询

## 查询当前的数据库名称

```sql
select sys_context('USERENV','DB_NAME') from dual
```

## 获取 Schemas

```sql
SELECT username FROM dba_users ORDER BY username
```

## 获取 Tables

```sql
SELECT table_name FROM dba_tables WHERE
    nvl(tablespace_name, 'no tablespace') NOT IN ('SYSTEM', 'SYSAUX')
    AND OWNER = 'SYSTEM' AND IOT_NAME IS NULL
```

## 获取 Views

```sql
SELECT view_name FROM dba_views WHERE owner = 'SYSTEM'
```

## 获取 Table 描述

```sql
SELECT comments
    FROM dba_tab_comments
    WHERE table_name = CAST(:table_name AS VARCHAR(128))
    AND owner = CAST(:schema_name AS VARCHAR(128))
```

## 获取表和视图的定义语句

```sql
SELECT DBMS_METADATA.GET_DDL('TABLE','表名') FROM DUAL;
SELECT DBMS_METADATA.GET_DDL('VIEW','视图名') FROM DUAL;
SELECT DBMS_METADATA.GET_DDL('MATERIALIZED_VIEW','物化视图名') FROM DUAL;
```
