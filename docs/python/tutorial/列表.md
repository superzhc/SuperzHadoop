# 列表

> **列表** 是任意对象组成的序列。
> 
> 把值放入方括号中就可以创建列表，列表使用从0开始的整数索引，使用索引运算符可以访问并修改列表中的项
> 
> 1. 要将新项追加到列表末尾，可使用 `append()` 方法
> 
> 2. 要将一项插入到列表中，可使用 `insert()` 方法
> 
> 3. 使用切片运算符可以提取一个子列表或对子列表重新赋值
> 
> 4. 使用加号（ + ）可以连接列表

> 创建一个空列表有两种方式：
> 
> ```python
> names = []        # 一个空列表
> names = list()    # 一个空列表
> ```
