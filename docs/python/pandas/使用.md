# 使用

## 数据查看

### 数据基本信息

```py
df.info()
```

### 数据维度

查看数据有多少行多少列

```py
df.shape
```

### 查看数据量

```py
df.size
```

### 查看前几条数据

```py
df.head()
```

### 查看后几条数据

```py
df.tail(3)
```

### 索引

```py
df.index
```

### 列名

```py
df.columns
```

### 数据信息

```py
df.values
```

### 描述性统计

```py
df.describe()
```

### 数据转置

```py
df.T
```

### 根据指定列数值进行排序

```py
df.sort_values(by="[列名]")
```

## 数据修改

### 修改列名

```py
df.rename(columns={
    "oldColumnName1":"newColumnName1",
    "oldColumnName2":"newColumnName2",
    "oldColumnName3":"newColumnName3",
})
```

### 新增固定列

```py
df["列名"]="列值"
```

### 新增计算列

```py
df["列名"]=df["已有列1"]+df["已有列2"]
```

## 数据选取

### 获取单列数据

```py
df["<列名>"]
# 等效于
df.<列名>
```

### 按行选取数据

```py
df[<startIndex>:<endIndex>]
```

## 导入导出数据


**将数据写入csv，如果有中文需要注意编码**

```py
df.to_csv('foo.csv')
```

**从csv中读取数据**

```py
pd.read_csv('foo.csv').head()
```

**将数据导出为hdf格式**

```py
df.to_hdf('foo.h5','df')
```

**从hdf文件中读取数据前五行**

```py
pd.read_hdf('foo.h5','df').head()
```

**将数据保存为xlsx格式**

```py
df.to_excel('foo.xlsx', sheet_name='Sheet1')
```

**从xlsx格式中按照指定要求读取sheet1中数据**

```py
pd.read_excel('foo.xlsx', 'Sheet1', index_col=None, na_values=['NA']).head()
```
