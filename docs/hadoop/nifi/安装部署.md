# 安装部署

> **基于 NiFi v1.21.0**
>
> 官方下载地址：<https://nifi.apache.org/download/>
> 
> 官方下载目录：<https://archive.apache.org/dist/nifi>
> 
> 下载地址：<https://archive.apache.org/dist/nifi/1.21.0/nifi-1.21.0-bin.zip>

## 下载解压文件

```bash
# 1. 下载文件
# 2. 解压文件
unzip -o nifi-1.21.0-bin.zip
```

## 应用管理

**0. 进入nifi安装目录**

```bash
cd nifi-1.21.0
```

**1. 启动nifi**

```bash
# 方式一：前台运行nifi
bin/nifi.sh run
# 方式二：后台运行nifi
bin/nifi.sh start
```

**2. 查看nifi状态**

```bash
bin/nifi.sh status
```

**3. 停止nifi**

```bash
# 前台运行nifi的直接使用 ctrl+c 即可关闭nifi

# 后台运行nifi的停止方式
bin/nifi.sh stop
```

**4. 重启nifi**

```bash
bin/nifi.sh restart
```

### Windows 启动

```bash
run-nifi.bat
```

## 配置管理

进入配置目录 `${NIFI_HOME}/conf`

**修改 nifi 默认端口**

```bash
# nifi.properties
# 关闭https
nifi.web.http.host=0.0.0.0
nifi.web.http.port=4000
```
