# TaskManager

|配置项|默认值|描述|
|------|-----|-----|
|`taskmanager.heap.size`|`1024m`| TaskManagers的JVM堆大小，它是系统的并行工作者。在YARN设置中，此值自动配置为TaskManager的YARN容器的大小，减去一定的容差值|
|`taskmanager.numberOfTaskSlots`|`1`|单个TaskManager可以运行的并行算子或用户函数实例的数量|
