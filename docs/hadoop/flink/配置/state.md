# State

|配置项|默认值|描述|
|------|-----|-----|
|`state.backend`||状态后台用于存储和检查点状态|
|`state.checkpoints.dir`||用于在 Flink 支持的文件系统中存储检查点的数据文件和元数据的默认目录.所有 TaskManagers 和 JobManagers 访问存储路径.|
|`state.savepoints.dir`||保存点的默认目录.由将后台写入文件系统的状态后台（MemoryStateBackend，FsStateBackend，RocksDBStateBackend）使用|
